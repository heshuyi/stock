# 移动端逐页检查细项

断点约定：手机默认 `<640px`（Tailwind `sm` 以下）；验收宽建议 **375** 与 **390**。

## layout / 全局

- [ ] `metadata.viewport` 或等价 viewport meta 正确
- [ ] `body` / 根容器无整页横向滚动
- [ ] 底部安全区：`padding-bottom: env(safe-area-inset-bottom)`（底栏或主内容）
- [ ] 顶栏品牌在窄屏不撑破一行；副标题可截断
- [ ] `<sm` 底栏 Tab：今日 / 策略 / 行情 / 数据库 / 设置
- [ ] `sm+` 顶栏 nav 可见，底栏隐藏
- [ ] 链接/按钮 `:active` 或 hover 在触控下仍有反馈

## 今日操作 `/`

- [ ] 标题区与「今日合计 / 同步」在窄屏纵向堆叠
- [ ] 同步 / 强制全量触控区域足够；不与合计块重叠
- [ ] OperationCard：名称+徽章可换行；金额区可读
- [ ] 展开明细网格在手机为单列

## 策略对比 `/strategies`

- [ ] 标的 Chip 横滑或舒适换行
- [ ] 柱状图高度随断点变化；X 轴标签不重叠
- [ ] 对比表 `overflow-x-auto`

## 标的详情 `/market`

- [ ] 统计卡 `grid-cols-2`（手机）→ `sm:grid-cols-4`
- [ ] 三张图高度降档；双列图在 `lg` 才并排
- [ ] Tooltip 不导致页面横向溢出（容器 `overflow-hidden` 可接受）

## 数据库 `/database`

- [ ] 概览 Stat 卡 2 列
- [ ] 筛选控件全宽/多行；日期控件不裁切
- [ ] 明细表横向滑动；表头 sticky 仍可用
- [ ] 上一页/下一页在窄屏左右贴边，中间说明可隐藏

## 持仓与设置 `/settings`

- [ ] 表单字段全宽；checkbox 行可点区域大
- [ ] 持仓块字段在手机单列或 2 列，勿 4 列挤爆
- [ ] 保存按钮在内容下方易找；可选底部 sticky（注意避让底栏）

## 回归

- [ ] 桌面 1280 宽：顶栏 nav、图表高度、多列网格恢复
- [ ] 深链进入各页底栏高亮正确（若实现 active 态）
