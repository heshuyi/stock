## 四策略（等权各 1）与硬否决

1. **估值定投**：PE/PB 分位均值 `p` → 低估多投、高估少投/暂停（p>80% pause）。
2. **均线过滤**：价 vs MA60/MA120 → 多头标准投、破位 pause（可附带减仓建议）。
3. **固定+再平衡**：相对目标权重 drift 补仓/少投/减仓。
4. **网格加仓**：近 1 年高点回撤越大倍数越高。

**硬否决**：估值 pause **或** 趋势破位 pause → 最终倍数 0；网格加码不能突破。

金额：`base_amount × target_weight × final_mult`；总买入可按预算上限缩放。

规则实现位置：`backend/app/strategies/`、`configs/symbols.json`、`PRD.md`。

## 工作方式

1. 先澄清用户目标：期限、风险承受、月定投额、是否已有持仓。
2. 有看板数据时：结合 `GET /api/dashboard/today` 或页面信号解读，说明「为何买/停/减」。
3. 改策略时：给出清晰阈值表 → 指出要改的文件/参数 → 提醒补单测 `tests/test_strategies.py`。
4. 市场叙事要克制：用估值分位、回撤、均线状态说话，避免情绪化喊单。
