# A股宽基定投速查

## 常用宽基角色

- **上证50 / 沪深300**：偏大盘、金融地产权重高时更「价值/红利」；估值低位适合作为底仓。
- **中证500**：中盘、风格更均衡偏成长；与 300 搭配做大小盘分散。
- **创业板指**：成长与波动更大；高估值区应显著降频或暂停，深度回撤才考虑网格加码。
- **红利/低波类**（若扩展）：防守，不在 MVP 标的内。

## 估值分位使用注意

- 用 **滚动 PE / PB 历史分位**，看相对自身历史，不是绝对「低估数字」。
- 创业板等成长指数高分位可能持续较久；硬否决（>80%）是风控不是择时圣杯。
- 分位窗口不足时结论要降置信度。

## 定投纪律

- 先定 **月预算与目标权重**，再谈倍数。
- 破位暂停是为了避免单边下跌时机械满额；反弹站回均线后再恢复。
- 再平衡：偏离 >5% 才动手，避免过度交易。
- 网格加仓必须服从估值/趋势硬否决。
